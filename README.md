Hey, I'm **Sorty** 👋

I love building practical, reliable applications for mobile, web, and hardware. Rather than getting bogged down in theory, I like jumping into the workshop, prototyping rapidly, and building software that solves real friction.

* 📱 **Currently Scaling**: **[Schedly](https://github.com/sorty11/Schedly)** — an atomic timetable and push notification engine for university departments.
* 🛠️ **Favorite Workflow**: Flutter on the frontend, Firebase & Node on the backend, and clean architecture under the hood.
* 🔍 **R&D Interests**: Real-time message dispatching, offline-first syncing, and computer vision gesture control.
